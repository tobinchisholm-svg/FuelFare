# FuelFare

## Purpose
FuelFare calculates the gas cost of driving from point A to point B, using
route distance from a map service, the driver's specific vehicle (year,
make, model, engine), and current gas prices in their zone. It helps drivers
budget, split gas costs fairly, and track driving expenses.

## Intended Users
- Visitors: quick trip cost estimates and gas price lookups
- Drivers: saved vehicles, saved trips, cost splitting, and trip history
- Administrators: manage the vehicle catalogue and weekly gas prices

## Technology
Django API · PostgreSQL · map/routing service · integrated with
WEBD 3100 (interface) and PROG 2700 (dynamic functionality)
